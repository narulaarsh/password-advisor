# Draft request for the full PASS dataset

The PASS page asks for requests by email to `hanghu[AT]vt.edu`. That page and address date from 2018, so check the current contact on the authors' pages before sending. The request should come from the faculty supervisor, using an institutional email address.

---

**Subject:** Request for the PASS password dataset for academic research

Dear Dr. Hu and Prof. Wang,

I am [name and position] in the Department of Computer Science and Engineering (Information Security) at Vellore Institute of Technology, India. I am supervising a student project that evaluates local, privacy-preserving detection of cross-account password reuse and modification in a password manager.

We have evaluated our method on the public 1,000-user sample of the PASS dataset, which is cited as Wang et al., "The Next Domino To Fall", ACM CODASPY 2018. We would like to request the full dataset in order to:

1. Measure detection of exact reuse and of derivative passwords at scale.
2. Compare our method against published password-strength meters on the same targets.

The data would be:

- stored encrypted on institutional machines
- accessible only to the project members [names]
- never redistributed
- reported only in aggregate form
- deleted at the end of the project [date]

Our analysis does not query any external service with the passwords. [Add the ethics approval reference if one is held.]

We will cite your paper in any resulting publication. Thank you for considering this request.

Kind regards,
[name, position, institution, institutional email]
